# VibeDesign

Репозиторий проектов. Каждый проект находится в своей папке внутри `projects/` и содержит собственные исходники, зависимости и инструкции по запуску.

## Проекты

| Проект | Описание | Версия |
| --- | --- | --- |
| [Таблица золота](projects/gold-table/) | Интерактивный график цены золота: desktop/mobile, периоды, состояния загрузки и ошибки | v159 |

## Запуск первого проекта

Требуется Node.js 22.13+ и npm.

```sh
cd projects/gold-table
npm ci
npm run dev
```

Команды установки, тестирования и сборки выполняются из папки нужного проекта. У проектов отдельные `package.json` и lockfile; общая установка зависимостей из корня не настроена.

- [Инструкция разработчику](projects/gold-table/README.md)
- [Макеты Figma и отличия от реализации](projects/gold-table/docs/FIGMA.md)
- [Результаты проверки](projects/gold-table/docs/VALIDATION.md)

## Добавление проекта

Создайте `projects/<имя-проекта>/`, разместите там код, зависимости и README с командами запуска. Добавьте проект в таблицу выше. Общие библиотеки можно выделить позднее, когда появится потребность в совместном использовании кода.
