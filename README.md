## Запуск

Все команды ниже выполняйте из корня репозитория.

Требуется Node.js 22.13+ и npm. `.nvmrc` выбирает ветку Node.js 22.

```sh
npm ci
npm run dev
```

Откройте локальный адрес из терминала. Ключи API и подключение к ChatGPT Sites не требуются. Для свежих цен серверу нужен доступ к Банку России; при сбое используется встроенная история.

| Адрес | Назначение |
| --- | --- |
| `/` | Панель прототипа: B/A/C/D, desktop/mobile, состояния данных |
| `/preview?variant=b` | Основной график B без панели |
| `/preview?variant=b&slow=5` | Медленная первоначальная загрузка, 5 секунд |
| `/preview?variant=b&failure=1` | Сбой обновления при доступной сохранённой истории |
| `/preview?variant=b&empty=1` | Ошибка без истории; «Повторить» демонстрирует восстановление |
| `/api/gold-prices` | Серверный маршрут обновления котировок |

Параметры `slow`, `failure`, `empty` демонстрационные. При `empty=1` повторная попытка может восстановиться из встроенного снимка — это поведение прототипа.

## Проверка и сборка

```sh
npm test
npm run typecheck
npm run build
npm start
```

`npm start` запускает локальный Wrangler для собранного Worker; это локальная проверка, не публикация. Стек: React 19, TypeScript, vinext/Vite, Tailwind CSS и Cloudflare Workers. Для другого хостинга адаптируйте серверный маршрут и сборку. Результаты проверки — [docs/VALIDATION.md](docs/VALIDATION.md).

При выделении графика в отдельный компонент сохраняйте его CSS, зависимости, шрифты и серверный маршрут.

## Данные и поведение

- Периоды: 1, 5, 10 и 15 лет, по умолчанию 5 лет. Вариант B выбран по умолчанию.
- Источник: [Банк России](https://www.cbr.ru/scripts/xml_metall.asp), золото `Code=1`, `Buy`, рубли за грамм — учётная цена ЦБ.
- Встроенная история — резервный снимок. Его дата и источник указаны в `app/gold-price-history.ts`. Живые значения могут отличаться от фиксированных данных Figma.
- Клиент обновляет данные при открытии, каждые 5 минут на видимой вкладке, при возвращении на вкладку и фокусе окна. Сервер кеширует до 5 минут и сбрасывает кеш при смене московской даты.
- Будущие по московской календарной дате котировки исключаются. При недоступности ЦБ график использует историю; API возвращает HTTP 503 и `{ "prices": [] }`.
- Доходность: `(цена / цена начала периода − 1) × 100`. Подписи округлены до целых рублей и процентов; расчёты сохраняют исходную точность. Сглаживание кривой не меняет котировки.
- Морфинг периода — 750 мс с логарифмическим изменением временного окна. Учтён `prefers-reduced-motion`.
- Лоадер появляется после 300 мс и затем остаётся видимым минимум 500 мс. Шрифты ошибки загружаются до её раскрытия для стабильных размеров текста.
- Вариант B поддерживает desktop hover и касания, исторические и текущие бейджи, доходность в выбранном периоде и анимацию текущего значения.
