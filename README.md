# График цены золота

Последняя версия прототипа на 30 сентября 2026. Передача разработчику.

## Запуск

Требуется Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает терминал. `/` — переключатель десктопной/мобильной версии и режима медленной загрузки (5 секунд). `/preview` — сам блок графика без панели прототипа.

```sh
npm run build
npm start
```

Сборка использует React 19, TypeScript, vinext/Vite и Cloudflare Workers. Это самостоятельный проект: подключение к ChatGPT Sites не требуется. Для другого хостинга адаптируйте серверный маршрут `/api/gold-prices`.

## Что передано

График с периодами 1, 5, 10 и 15 лет, по умолчанию 5 лет. Мобильная и десктопная версии, состояния загрузки и взаимодействия, актуальные расчёты, исторический снимок цен ЦБ. Экспериментальные страницы лаборатории не включены в маршруты. В исходном `gold-landing.tsx` остались неиспользуемые секции и ветки калькулятора: они не отображаются в этом проекте.

## Где искать

- `app/gold-landing.tsx`: PriceChart, PriceHistorySection и GoldChartPreview; расчёт координат, анимации и взаимодействия.
- `app/globals.css`: стили, мобильные правила, шрифты, лоадер и появление подписей.
- `app/gold-price-history.ts`: резервный исторический снимок.
- `app/api/gold-prices/route.ts`: обновление цен из ЦБ.
- `app/page.tsx`: панель просмотра версий.
- `app/preview/page.tsx`: график для встраивания.

## Данные и расчёты

Источник: https://www.cbr.ru/scripts/xml_metall.asp — золото, Code=1, Buy, рубли за грамм. Дата отсечения — текущий день Москвы; будущие котировки не включаются. Сервер обновляет последние котировки, кеширует на час, при ошибке клиент использует встроенный снимок. Обновление при загрузке страницы, без постоянного опроса. Доходность: `(цена / цена начала периода − 1) × 100`. Для даты без котировки берётся последняя доступная цена не позже этой даты. Подписи округлены до целых рублей и процентов; расчёт использует исходную точность. Сглаживание касается визуализации, а не исторических цен подписей.

## Поведение для сверки

- Первое появление: линия раскрывается слева направо, затем появляются данные.
- Лоадер: задержка 300 мс, после появления показывается минимум 500 мс.
- Морфинг: 750 мс, косинусное замедление, логарифмическое изменение временного окна; диапазон цен меняется с тем же прогрессом. Опорные точки истории сохраняются, линия обрезается по таймлайну.
- Во время морфинга исторические точки и бейджи скрыты, пунктиры остаются; затем лёгкое появление.
- Десктоп: 5 отметок времени, промежуточные даты через равные календарные интервалы в месяцах.
- Мобильная: 4 отметки времени; линия стилистически продолжается за левый край.
- Ховер: движущаяся точка и тёмный бейдж у курсора, текущая точка остаётся. На текущей цене дополнительный бейдж не появляется.
- Мобильная: бейдж только во время удержания пальца, свободное перемещение, отступ вверх минимум 16 px; отпускание скрывает бейдж.
- Учтён prefers-reduced-motion.
