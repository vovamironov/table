# Взаимодействие графика — v161

Реализация от 21.10.2026, основной вариант B. Настройки ниже одинаковы для desktop и mobile web. Они меняют выбор данных для ховера; кривая строится по полной истории.

| Период B | Данные для выбора |
| --- | --- |
| 1 год | Каждый календарный день |
| 5 лет | 15-е число каждого месяца, около 60 месячных точек |
| 10 лет | 15-е число каждого месяца, около 120 месячных точек |
| 15 лет | 15-е число каждого месяца, около 180 месячных точек |

Для выбранной даты берётся последняя опубликованная котировка ЦБ не позже этой даты. Выходные и другие дни без новой котировки переносят предыдущее значение. Это цена, действовавшая на 15-е число, а не среднемесячная цена. Неполный месяц добавляет 15-е число только тогда, когда оно уже входит в период.

К сетке добавляются точный старт периода, подписанные исторические ориентиры и текущая дата. Совпадающие дни объединяются с приоритетом значения ориентира. Постоянных временных отметок 5 на desktop и 4 на mobile. Они делят период на равные временные участки; их даты не обязательно приходятся на 15-е число. Поэтому итоговое число выбираемых точек немного больше количества месяцев.

В периодах 5/10/15 лет B точка и вертикальная направляющая непрерывно следуют указателю по сглаженной линии. Бейдж показывает данные ближайшей точки по времени; при точном равенстве расстояний выбирается более ранняя. Отображённая дата и сумма связаны между собой. Координата движущейся точки — позиция на визуальной кривой, она не означает отдельную котировку для каждого промежуточного пикселя. За 1 год координата привязана к выбранному календарному дню.

Текущая дата присутствует в сетке, но отдельный ховер для неё не показывается: в последних 8 CSS px перед текущей точкой выбор сбрасывается. В месячном режиме, если ближайшей стала текущая дата, до этой зоны показывается предшествующая доступная точка. При активном ховере B скрывает постоянные исторические бейджи, их пунктиры, текущий бейдж и текущую точку; остаются линия таймлайна без засечек, выбранная дата и точка ховера. После завершения ховера элементы плавно возвращаются.

## Максимум периода

Максимум определяется по исходным котировкам выбранного периода. В B он доступен отдельно от месячной сетки, если находится строго между стартом и текущей датой. Во время морфинга притяжение отключено.

- В пределах ±4 CSS px по горизонтали точка притягивается к точной дате и цене максимума.
- При входе запускаются сплэш, частицы и радарная волна; весь график остаётся неподвижным.
- После ухода дальше 12 CSS px эффект снова готов к срабатыванию. Сброс выбора также снимает флаг входа; интервал между сплэшами в любом случае не меньше 800 мс.
- Смена периода, варианта, данных или размеров графика сбрасывает состояние эффекта.
- При `prefers-reduced-motion: reduce` сплэш отключён, выбор данных сохраняется.
- На первой прорисовке сплэш пика не запускается автоматически.

## Управление

На desktop ховер обновляется при движении мыши; уход указателя за график сбрасывает выбор. На mobile он появляется по нажатию и движется при удержании благодаря pointer capture; отпускание или отмена касания скрывает его. После завершившегося тапа бейдж не остаётся. Смена периода сбрасывает активный выбор. До окончания первоначального раскрытия линии выбор недоступен.

A и C используют дневные точки во всех периодах. В D ховер отключён. Доходность в бейдже рассчитывается относительно стартовой цены выбранного периода и округляется до целого процента; суммы показываются в целых рублях. Исходные значения сохраняют точность.
